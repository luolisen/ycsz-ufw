# 通用客户端与反破坏验证任务

## 本轮范围

1. 先发布当前 v0.1.0 工程预览，包含安装恢复记录；然后修改通用客户端。
2. 管理端导出可重复部署的客户端 ZIP，内含客户端专用安装程序和加密接入包。同一份交付包部署多台计算机，不再逐台填写设备名称。
3. 每台客户端在安装时生成独立 ID 和随机接入令牌，以 Windows 计算机名称显示；同名计算机不合并。共享接入包仅用于首次注册，不能直接用于设备心跳或冒充已存在设备。
4. 保持原密码保护、逐设备策略、代理处理、网络基线、解冻/冻结和管理员恢复路径。现有单设备接入包仍可读取。
5. 兼容旧管理端配置。升级本身不覆盖旧配置，不在当前唯一管理主机运行客户端防护以免影响远程管理链路。

## 实现与验证

- 接入协议：重试幂等、独立设备凭据、撤销不可重注册恢复、设备数和接入包数有上限；错误输入在写入前拒绝。
- 通用客户端导出：客户端专用安装程序随管理端安装；导出 ZIP 中仅含通用安装器和加密接入包，不写明文管理密码。
- 计算机名称：首次注册与后续认证心跳更新显示名称，内部仍用独立 ID 关联策略。
- 反破坏：按攻击面、验证步骤、结果、风险记录标准用户对服务/安装目录/配置目录的权限，IPC 未授权调用，凭据保护，服务恢复，UAC 和合法管理员恢复边界。
- 本地自动测试覆盖注册/冒用/撤销/配额/重试和原有网络逻辑。Windows CI 使用隔离临时目录和受控测试服务验证权限及恢复；不可运行的项目明确标记未验证。
- 不隐蔽持久化、不绕过 UAC，不阻止合法管理员卸载；不修改当前 Mac 的网络或防护配置。

## 交付

源码、通用客户端安装包、完整 ZIP、哈希、安装恢复记录与安全验证报告。新功能以 v0.2.0 工程预览独立记录，不覆盖 v0.1.0 的实机验证证据。
