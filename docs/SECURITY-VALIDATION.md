首次测试曾发现 Mono 对嵌套显式 union 的对齐方式与 Windows x64 ABI 不一致，已将 WFP 条件及过滤器结构改为显式偏移。这个修复通过布局测试，**仍不能替代 Windows 的 FwpmFilterAdd0 实测**。

## 2.1 网络回滚逻辑补测

新增 `scripts/Test-NetworkLogic.ps1`，直接加载生产 Capture/Apply 函数，将网络 cmdlet 替换为测试桩，只读写临时 hosts 文件。9/9 通过：删除检测、删除后重建、仅 hosts 漂移不写网卡、完全无变化不写配置、恢复初装缺失状态、仅 IPv4 DHCP 变化、仅 IPv4 DNS 变化、网卡缺失时仍恢复 hosts 并报错、新增网卡仅禁用目标。另新增空 hosts 与已删除 hosts 的 C# 差异测试。

修复前 hosts 删除会使读取失败而不能自动重建；修复后快照显式记录文件是否存在。网卡配置应用也改为仅写变化的 DHCP/DNS 项。以上是模拟网络对象的本机逻辑测试，不是 Windows cmdlet 实测。证据：`artifacts/network-logic-results.txt`。

## 2.2 配置失败与安装恢复复核

远程网络命令在改动系统前持久化尝试版本；应用失败或服务中途重启后，不会每 15 秒重试同一失败版本。管理端重新保存配置生成新版本才再试。新增两项测试，覆盖失败标记序列化/重启后的抑制、新版本重试、已应用及空命令。客户端状态会显示网络配置失败。

安装器只为管理端创建入站规则；配置入站规则失败时停止安装，不启动服务。卸载若无法删除服务，保留程序和卸载登记，避免留下服务指向已删除文件。这些 NSIS 分支通过编译，实际系统效果仍需 Windows 验收。

## 5. 剩余风险与未满足项

1. **严格网址隔离未实现**：当前为域名解析到 IP 后的 TCP 80/443 放行。共享 CDN、DNS 完整性和白名单站点的转发能力可能扩大可访问范围；不能声称仅能访问特定 HTTPS 域名或所有且仅限备案网站。
2. **ICP备案核验未完成**：预置教育/政务/公共信息域名为候选，不是官方备案数据库的完整或已实时核验名单。
3. **系统配置覆盖有界**：不重建被删除的硬件/驱动；不覆盖全部高级网卡、无线、NIC teaming 或第三方隧道设置。未加载用户配置不主动挂载处理。
4. **名称检测有界**：改名、短命进程可能不被名称轮询识别；不包含反恶意软件内核驱动。
5. **不对抗合法管理员**：不隐藏卸载、不绕过 UAC、不阻止管理员恢复。标准学生账户是运行前提。
6. **服务、审计与网络可能被域策略/其他安全软件影响**：需要现场验证 WFP 仲裁、审计位和网络例外；DHCP/DNS、回环和管理通道是明确放行例外。
7. **未签名工程预览包**：没有 Authenticode 代码签名与产品发布证书；不能描述为正式签名发布版本。未向远端发布。
8. **日志为有界近期记录**：客户端最多待传 2000 条、管理端每机近期 200 条，非永久合规审计系统。证书有效期 3 年，需计划轮换注册。
9. **Windows 运行验收缺失**：包含源码不代表各个 Windows API 路径均已正确运行；需要 W01–W20 的实际结果后才能评估机房上线。
