## 可复现证据

1. 桌面原安装包启动后，点击安装，提示无法打开要写入的文件 `C:\Program Files\YcszFirewall\Ycsz.exe`。
2. 管理员 PowerShell 查询 `Get-Process Ycsz` 和 `Get-Service YcszFirewall`，均不存在，未发现本产品进程占用或已安装服务。
3. `icacls` 显示安装根目录有 SYSTEM、Administrators 完全控制以及 Users 读取执行权限，所有者为 Administrators；但 `Ycsz.exe` 没有显示任何访问规则，`Get-Acl` 的 Access 列也为空。
4. 对本产品安装树执行 `icacls ... /reset /t`，11 个对象成功，0 个失败。只重置本产品目录，继承 Program Files 默认权限，没有修改系统其他目录或数据配置目录。
5. 再次运行原安装器，成功写入文件，随后出现“安装目录所有者设置失败，安装已停止”。详细日志显示权限阶段处理 12 个对象成功，所有者阶段在 `PLAN.md` 处报“句柄无效”，2 个成功、1 个失败。

上述结果表明原安装脚本的递归权限操作与失败后无法重试直接相关。修复后的具体行为仍需 Windows 回归确认。

## 本地修复

`installer/Ycsz.nsi`：

- 在解压文件前设置安装根目录权限；移除将目录继承标志递归授予每个文件的 `/T`。
- 对已存在的已知安装载荷路径执行 `/reset /T`，让其继承已受保护的根目录权限，修复中断安装留下的不可写文件。
- 然后解压文件并设置所有者，保留每步失败检查。
- 加入可选 `OUTPUT_FILE` 构建参数，修复包独立命名，保留原包作为复现对照。
