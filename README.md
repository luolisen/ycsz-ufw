# YCSZ 教育机房防火墙

原生 WinForms + Windows 服务；C# / .NET Framework 4.5 API 目标；Windows 10/11 x64、.NET Framework 4.8、Windows PowerShell 5.1。

**0.1.0 是待 Windows 实机验收的工程预览版本。** 请先在可回滚虚拟机验证，不要把交叉编译成功理解为机房部署验收通过。

详见 [任务规格](TASK.md)、[执行计划](PLAN.md) 和 [验证记录](docs/SECURITY-VALIDATION.md)。

## 构建

macOS：安装 Mono、NSIS 后运行 `./scripts/build.sh`。输出 `artifacts/Ycsz-Setup-0.1.0-x64.exe`。

Windows：运行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build.ps1`；不需要 NuGet 依赖。

可选设置 `YCSZ_PWSH=/path/to/pwsh` 后运行本机构建，以同时执行真实回环 TLS 和 PowerShell 语法测试。详细实现见 [架构说明](docs/ARCHITECTURE.md)。

## 安装顺序

1. 在固定 IPv4 的管理端运行安装包，选择管理端，设置至少 12 字符的管理密码。安装需要 UAC。
2. 打开开始菜单管理界面并验证密码，注册客户端：填写设备名、管理端固定 IPv4、注册包密码，导出加密 `.ycsz` 文件。
3. 在客户端运行同一个安装包，选择客户端、设置本机管理密码、导入注册包。初始化时必须能够连接管理端 TCP 17443，验证证书及令牌后保存网络基线。
4. 安装完成后重新登录以启动托盘，或手动运行 `Ycsz.exe --tray`。SHIFT + 左键点击托盘并输入密码进入管理。
5. 管理端修改统一白名单、选定设备解冻/冻结，查看客户端实际应用版本及事件。网络与 hosts 页可修改所选客户端的配置基线。

安装自动创建仅域/专用网络、本地子网的管理端入站规则。跨 VLAN 部署需要管理员另行配置正确的精确来源子网；不要直接开放公网。

## 能力边界

- 白名单网站仅放行 TCP 80/443；域名解析为 IPv4/IPv6 地址，共享 CDN IP 可导致其他域名被一并放行。不是严格 HTTPS 域名过滤，不解密 TLS。
- 预置域名是待审核候选，不代表逐项实时核验 ICP 备案，更不代表所有备案网站。需自行补齐站点依赖域名。
- 进程识别按文件名，改名程序可绕过名称匹配；出口限制独立生效。
- DNS/DHCP、回环和限定程序的管理通道属于必要例外。
- 网卡配置可恢复，已删除驱动/硬件不能自动重建；新增 IP 网卡禁用而不删除驱动。
- 解冻只解除本产品的出口限制，既有系统防火墙规则仍有效；进程、代理和配置保护继续执行。
- 不隐蔽安装、不绕过 UAC、不阻止合法管理员恢复。控制面板保留卸载记录。

## 恢复与卸载

正常卸载：本机管理页“卸载本机软件”，通过 UAC 并验证密码。也可从控制面板发起，同样需要密码。

管理员紧急恢复（管理员 PowerShell）：

```powershell
& "$env:ProgramFiles\YcszFirewall\Ycsz.exe" --recover
```

恢复停止服务，只移除 YCSZ 的 WFP 规则并恢复本产品更改的审计位，不删除网卡、全局防火墙或用户资料。恢复后服务保持停止，下次手动/系统启动服务会重新应用策略。

卸载保留 `C:\ProgramData\YcszFirewall` 中的加密配置、初始基线与日志。需要重新安装时，由管理员先停止/卸载旧服务并把该目录移至安全归档位置，再运行安装包。不要直接覆盖旧基线。

密码不可找回。恢复入口依赖合法 Windows 管理员权限；学生应使用标准用户账户。注册包密码与文件应分开传递。
